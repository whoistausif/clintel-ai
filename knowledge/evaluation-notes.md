# Cohort and evaluation notes

The demonstration readmission target is an unplanned readmission within 30 days after the index discharge time. This target definition is illustrative and needs study-specific review. Avoid using any outcome timestamp or post-index information as a feature.

Evaluation metrics for imbalanced outcomes include AUROC and AUPRC, plus precision, recall, F1, a confusion matrix, and calibration measures. Include confidence intervals where feasible. Review performance across relevant subgroups and over time. Synthetic-data performance is a software demonstration only and is not evidence of clinical validity.
