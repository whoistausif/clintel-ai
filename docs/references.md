# Dataset and schema references

- MIMIC-IV access policy, required credentialing, data-use agreement, and training: [PhysioNet MIMIC-IV](https://physionet.org/content/mimiciv/2.1/).
- Official MIMIC-IV module and identifier overview: [MIMIC-IV schema overview](https://mimic.mit.edu/docs/iv/about/schema-overview.html).
- Official admissions fields and caveats, including in-hospital death time: [MIMIC-IV admissions table](https://mimic.mit.edu/docs/iv/modules/hosp/admissions.html).
- Official laboratory event identifiers, units, and temporal linkage notes: [MIMIC-IV labevents table](https://mimic.mit.edu/docs/iv/modules/hosp/labevents.html).

The MIMIC query in this repository is a local adaptation template and must be checked against the downloaded version, table dictionaries, approved cohort definition, and access terms. The code does not download or include MIMIC data.
